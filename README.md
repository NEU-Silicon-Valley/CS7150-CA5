## **Overview**

This assignment has two parts. Each part has its own folder and README, and each is submitted on
its own:

| Part | Folder | Topic | Runs on |
|------|--------|-------|---------|
| **A (5a)** | [`CA5a_Segmentation/`](CA5a_Segmentation/) | Medical image segmentation with U-Net, on brain MRI scans | Explorer HPC (required) |
| **B (5b)** | [`CA5b_GenerativeModels/`](CA5b_GenerativeModels/) | Generative models: VAE, GAN, and diffusion | Anywhere |

Start with the README in each part's folder. It lists the notebooks, the points for each question,
the setup, and how to submit that part.

stuck on this part and looked it up" is a perfectly good answer. The point is to hear you reason
about your own code, not to catch anyone out.
